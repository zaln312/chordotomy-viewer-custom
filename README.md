# Chordotomy Viewer (Custom)

A customized [Chordotomy viewer](https://github.com/zeikar/chordotomy/tree/main/viewer) for chord visualization (piano & guitar), comparison, editing, and export.

## Usage

Open `index.html` in a modern desktop browser and load the following files:

- **Audio:** The original audio recording.
- **Chordotomy results:** A `.chords.json` file generated by [Chordotomy](https://github.com/zeikar/chordotomy).
- **ChordFormer results (optional):** A `.lab` file generated by [ChordFormer](https://github.com/shojha24/ChordFormer-Artificial-Dataset-Benchmarking).
